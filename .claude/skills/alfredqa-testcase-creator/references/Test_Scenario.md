此文件用來針對要產出的測試案例，提供具體的建議 （依照測試需求調整勾選/增加，未勾選則不參考）

### 測試場景建議加入測項

#### 基本情境
- [ ] 新用戶註冊
- [ ] 指定 OS 版本 (Android/iOS 最新官方OS版本)
- [ ] 核心功能交互不同平台間的測試 (Android/iOS/硬體相機)
- [ ] 轉換身份別 Membership 的測試 （Free/Standard/Plus）
- [ ] 硬體相機配對流程 AlfredCam (AC101/AC201/AC202)
- [ ] 相機端長時間錄影測試
- [ ] 監控端與相機端長時間即時影像連線
- [ ] 相機端低電量運作，比如電量至 20%

#### 異常情境（每次產出測案時一律納入第 5 節）

**A. 網路異常**
- [ ] 直播中網路斷線後恢復重連
- [ ] 直播中 WiFi 切換行動數據
- [ ] 弱網路（高封包遺失）下開啟 Cloud Playback
- [ ] 付款流程中途斷網
- [ ] 離線狀態下點擊 Paywall / Upsell CTA

**B. 螢幕方向異常**
- [ ] 關鍵遮罩頁面（CR Playback、Paywall）橫放手機
- [ ] 直播畫面橫放時操作功能選單
- [ ] Event Playback 橫放時 seek bar 操作

**C. App 生命週期異常**
- [ ] 訂閱流程中 App 被強制關閉再重啟
- [ ] 直播中 App 進入背景超過 5 分鐘後回前景
- [ ] CTA / 購買按鈕快速連續點擊 2 次（防重複購買）
- [ ] 關鍵流程中收到來電打斷

**D. 帳號與權限同步異常**
- [ ] 訂閱進行中登出再登入
- [ ] 換裝置後還原購買（Restore Purchase）
- [ ] 降級瞬間另一台裝置正在使用付費功能
- [ ] Camera 端與 Viewer 端方案不同時的計數/權限邏輯

**E. 儲存邊界異常**
- [ ] 本機儲存空間不足時新錄影行為
- [ ] Playback 播放中訂閱到期
- [ ] 儲存時限邊界（如 48 小時）的 seek 與刪除行為

**F. 偵測功能異常**
- [ ] 偵測功能啟用中訂閱到期
- [ ] 同時啟用超出方案限制的偵測組合
